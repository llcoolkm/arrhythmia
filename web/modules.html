Circus Arrhythmia FM: module files

Add, examine and delete the module files on the microSD card of the unit, without a card reader. The files go in the folder Modules on the card. This page runs in Chrome (tested; Edge untested) with Web MIDI and SysEx. The unit must run a Circus Arrhythmia FM firmware with the card writer. Installer

1. Connect the unit

Close Components and any other music app, then connect the unit by USB. Stop playback on the unit.

2. Modules on the card

A card command stops a running module on the unit. List and Verify are not only reads: before each job the unit tidies its helper files (NAME.TMP, NAME.OLD) left by an interrupted write.
