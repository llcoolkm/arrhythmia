Circus Arrhythmia FM: MIDI export

Export a project of the unit as a MIDI file for a DAW, with the samples it uses and a mapping for Drum Racks. The page reads the folder you open, or the unit over USB. It does not modify the project and sample files in either; it writes only the ZIP you download. It runs in Chrome. Nothing leaves the computer. Installer · Modules

1. Open the folder or read the unit

Open a copy of the microSD card (folder Rhythm), the folder files of a backup of the unit's internal storage, or one pack folder. The projects are in the folders Sessions, the samples in the folders PCM.

A project file outside a pack folder (NN_name.ncs, or a file that holds project files unchanged) gives a MIDI file and the mapping without sample files.

Read from unit lists the projects of a unit on USB; selecting a project reads it and the samples it plays. The unit runs Circus Arrhythmia FM 0.2.2 or the stock firmware 2.0.1, is stopped, and no other program (Components, the installer, a DAW) uses its MIDI port. Touch no control while the page reads. The track-8 synth pauses during a read and starts again by itself. Chrome asks for MIDI access once.
