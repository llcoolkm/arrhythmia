Arrhythmia

Custom firmware for the Novation Circuit Rhythm. An independent project, not affiliated with or endorsed by the maker of the instrument.

This installer runs in Chrome (tested; Edge untested) with Web MIDI and SysEx. Your stock firmware file is patched locally in this page; nothing is uploaded. Release: none

1. Connect the unit

Close Components and any other music app, then connect the unit by USB.

2. Choose the stock firmware

The stock firmware 5706 file you downloaded (download link). Any file name works.

Save patched .syx

3. Install

Leave the unit idle and keep this tab open. When Play flashes on the unit, press Play. Unplugging before the transfer finishes leaves the installed firmware untouched.
